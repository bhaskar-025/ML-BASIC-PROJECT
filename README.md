# ML-BASIC-PROJECT
# Handwritten Digit Recognition using CNN

## Features
- CNN model trained on MNIST dataset
- Predict handwritten digits from uploaded images
- 94% validation accuracy

## Technologies
- TensorFlow/Keras
- OpenCV
- NumPy
- Matplotlib

## Dataset
MNIST handwritten digit dataset

## How to Run

1. Clone repository
2. Install dependencies

pip install -r requirements.txt

3. Open CNN.ipynb
4. Run all cells

## Predict Your Own Image

Upload an image named `digit.png` and run the prediction cell.

## Model

The trained model is stored as:

digit_model.keras
